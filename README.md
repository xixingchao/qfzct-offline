# 潜伏之赤途 · 网页离线版存档

《潜伏之赤途》的离线可玩存档。原作是橙光游戏 2992，作者 **fantasia**（后来《隐形守护者》的原作），
原站 `https://www.66rpg.com/game/2992` 与 `h5/2992` 均已下架，只剩一个"谢谢支持"占位页。

本仓库基于同人镜像 <https://ssz66666.github.io/qfzct-66rpg/> 制作：把橙光 CDN 上的播放器引擎与全部游戏素材
落地到本地，改成不依赖任何外部服务的版本。

## 直接玩

开启 GitHub Pages 后访问仓库主页即可。素材、引擎、剧情数据全在本仓库内，**不需要任何外部请求**。

## 本地玩

下载整个仓库，双击 `启动.bat`（需要一个 Python），它会起 127.0.0.1:8126 并自动打开浏览器。
不要直接双击 `index.html`，`file://` 打开会黑屏——橙光这套引擎要求走 HTTP。

## 目录

```
index.html   入口（已改成本地资源）
map.json     资源表，381 条
assets/      游戏素材 381 个（图片 / 音频 / 剧情 data/game.bin），约 53.5 MB
engine/      橙光 H5 播放器引擎与皮肤，41 个文件，约 2.8 MB
启动.bat / 说明.txt
```
